# GrayVDoma — прототип редизайну

Статична сторінка для показу клієнту. Індексація вимкнена (`noindex`). GitHub Pages: корінь гілки `main` після злиття, адреса https://networxua.github.io/grayvdoma-demo/

Бойовий сайт: https://grayvdoma.in.ua/

## Що це

Один `index.html` без збірки. Мова — українська, тексти з живого сайту на 3.11.2026. Кошик, кабінет і оплата не зроблені: кнопки показують тост «у прототипі» або ведуть у Telegram.

## Запуск

Відкрити `index.html` або підняти будь-який статичний сервер з кореня репозиторію. Шляхи відносні.

Перший екран не тягне всі обкладинки: у сітці стоїть `loading="lazy"`. Логотип бойового сайту важив 1.3 МБ PNG, тут він 96 КБ WebP.

## Анімація

За `motion_standard`: без GSAP і без другої бібліотеки. Світло на екрані і бігуча обводка кнопки — CSS (`conic-gradient` + `@property`). Кроки підсвічуються через IntersectionObserver. Стрічка ігор гортається пальцем, без автопрокрутки. `prefers-reduced-motion` вимикає анімації. Текст і кнопки видимі без JS.

## Бібліотеки

Своїх JS-бібліотек немає.

- Manrope (Mikhail Sharanda), SIL OFL — `assets/fonts/OFL-Manrope.txt`
- Unbounded (Grigori Zhukov), SIL OFL — `assets/fonts/OFL-Unbounded.txt`

Файли шрифтів завантажені з Google Fonts і лежать у репозиторії, не з CDN.

## Обкладинки

Скопійовані з карток каталогу grayvdoma.in.ua і стиснені до ширини 520 px WebP. 145 карток на бойовому сайті мають битий `src` (`ff`, `aa` тощо), ще одна URL відповіла помилкою. Для них на прототипі корінець «Немає обкладинки», не намальований арт.
